 YOUR MODEL CONNECTION

Configure the project .env

Choose a provider and model. Credentials stay in the local Python process and are excluded from generated downloads.

AB_AGENT_PROVIDER=openai
AB_AGENT_API_URL=https://api.openai.com/v1
AB_AGENT_API_KEY=
AB_AGENT_MODEL=
AB_AGENT_PROTOCOL=responses

OpenAI-compatible endpoints can use AB_AGENT_PROTOCOL=chat. Anthropic uses AB_AGENT_PROVIDER=anthropic with its API URL. Local Codex uses AB_AGENT_PROVIDER=codex and your existing CLI login.

For a model without native tool calling, set AB_AGENT_TOOL_MODE=json.

To enable agent-run generator and verifier checks, set AB_AGENT_EXECUTION=local (runs generated Python under your account), or sandbox with Linux bubblewrap. Otherwise review files and enable checks here.

Settings are read again on the next message. See AGENT.md for setup and MCP tools.
